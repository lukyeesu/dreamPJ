# รูปสินค้า ฉลาก และการเลื่อนโหลดรายการ — 2026-11-13

## เปิดใช้

1. รันไฟล์ `database_scripts/inventory_compact.sql` รุ่นปัจจุบันทั้งไฟล์อีกครั้งใน SQL Editor ตามวิธีติดตั้งเดิม ชุดทดสอบตรวจการรันซ้ำและเก็บรูปเดิมแล้ว ไม่มีการรันฐานข้อมูลจริงโดยเอเจนต์
2. ในตั้งค่า → การเชื่อมต่อ → Google Drive ใส่ Folder ID แถว **รูปสินค้าในคลัง** แล้วบันทึก หากเว้นว่างใช้ Assets เดิม
3. เพิ่ม/แก้ไขสินค้า → เพิ่มรูปสินค้า → บันทึกรายการ รูปปรากฏในรายการคลังทั้งมือถือ/เดสก์ท็อปและตะกร้าเบิก
4. จัดการคลัง → พิมพ์ฉลาก QR → เลือก QR / Code 128 เลือกรหัสอุปกรณ์และขนาดก่อนพิมพ์ ถ้าไม่มีรหัสมีปุ่มเพิ่มรายชิ้นและสร้างรายการเครื่องมือก่อนต่อได้

## การเก็บข้อมูลและโควตา

- เพิ่ม `image_url` เพียงคอลัมน์เดียวในตาราง `inventory_items` เดิม คงแปดตารางคลัง
- รับ JPG/PNG/WebP ไม่เกิน 8 MB ย่อด้านยาวเหลือไม่เกิน 1024 px แล้วอัปโหลด JPEG ผ่าน Apps Script `uploadAsset` และ endpoint เดิมของร้าน
- ไฟล์อยู่ Google Drive; Supabase/IndexedDB เก็บเฉพาะ URL ที่ผ่านการตรวจสอบ ไม่เก็บ base64 หรือไฟล์รูปใน Supabase Storage
- รูปใช้ URL คงที่, lazy loading, ไม่มี cache-busting และไม่มีการอ่าน API แยกหนึ่งครั้งต่อรูป สิทธิ์อ่านไฟล์ต้องเป็นแบบเดียวกับรูป Assets ที่ร้านใช้อยู่
- บันทึกรายการล้มเหลวแล้วลองใหม่จะใช้ URL ที่อัปโหลดไว้ ไม่อัปโหลดไฟล์ใหม่ การยกเลิกฟอร์ม/เปลี่ยนรูปไม่ลบไฟล์ Drive อัตโนมัติ
- คลังเลื่อนโหลดต่อครั้งละ 50 รายการ มีปุ่มสำรอง ข้อมูลต่อท้ายและรวมตาม ID ไม่โหลดทั้งคลังพร้อมกัน ตัวกรองเริ่มที่หน้าแรกและคงของในตะกร้าไว้
- ไม่โหลดเพิ่มขณะซ่อนหน้า/อยู่แท็บอื่น/มีคำขอรออยู่/โหลดผิดพลาด เมื่อเกิดข้อผิดพลาดใช้ปุ่มโหลดเพิ่มเติมเพื่อลองใหม่
- เรียงชื่อร่วมกับ ID ให้ลำดับของสินค้าชื่อเหมือนกันแน่นอน ใช้การแบ่งหน้าแบบ offset; การแก้รายการโดยผู้ใช้อื่นระหว่างเลื่อนอาจต้องรีเฟรช
- ยังไม่ได้วัด egress จริงรายเดือน ไม่รับรองว่าจะไม่เกินโควตา 5 GB; รูปที่โหลดจาก Drive ไม่ใช่ไฟล์รูปที่ส่งออกจาก Supabase

## การตรวจสอบ

- SQL จริงใน PGlite: บันทึกรูป สืบทอดเมื่อไม่ส่งฟิลด์ ลบการเชื่อมรูป ตรวจ URL สรุป/ค้นรายการ และรัน installer ซ้ำรักษาข้อมูลเดิม
- DOM: อัปโหลดรูปครั้งเดียวเมื่อ retry บันทึก ป้องกันบันทึกระหว่างอัปโหลด ปิดความสามารถเมื่อ SQL ยังไม่รองรับ
- DOM ทั้งหน้า: คลัง 105 รายการ โหลด 50 → 100 → 105, ป้องกันโหลดซ้ำ คงตะกร้า สลับหน้า ค้นหาใหม่ และสร้างเครื่องมือ/รหัสจากหน้าพิมพ์ว่าง
- Barcode/QR: อ่านกลับด้วย ZXing ตรวจขนาดจริง และทดสอบ iframe เรียก print แบบจำลอง
- MCP วันที่ตรวจยังไม่มี browser host/native pipe จึงยังไม่ยืนยันภาพหน้าจอจริงทุก viewport, อัปโหลดไป Drive จริง, กล้องจริง หรือเครื่องพิมพ์จริง
